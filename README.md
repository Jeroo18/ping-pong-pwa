# Better Goal Software · bettergoalsoftware.com

Sitio publicado con GitHub Pages en **https://bettergoalsoftware.com**.

- `/` — Portafolio de Salvador Cuevas, Solutions Architect. Página estática con GSAP (ScrollTrigger y SplitText), Lenis para el scroll suave y Three.js para la red neuronal del inicio. En seis idiomas: español, inglés, portugués, francés, alemán e italiano (`?lang=en`, `?lang=pt`, …).
- `/proyectos/` — Apps y juegos de Better Goal.
- `/sastrecloud/` — Demo de SastreCloud.

## Estructura del portafolio

- `index.html` — contenido en español.
- `assets/js/i18n.js` — traducciones a los otros cinco idiomas.
- `assets/js/site.js` — animaciones y menú de idiomas.
- `assets/css/site.css` — estilos.
- `assets/vendor/` — librerías incluidas localmente.

Sin dependencias de compilación: se edita y se publica tal cual.
